Three ways to run it

Local installer
The connector runs on the user's machine, and credentials stay there. Good for pilots and individual teams.
Hosted API
A remote endpoint with single sign-on and per-tenant isolation. No install, central updates.
Customer infrastructure
The same container inside the customer's own cloud or data centre, for buyers with data-residency rules.
